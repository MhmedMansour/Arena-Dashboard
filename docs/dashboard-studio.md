# دليل التخصيص الشامل للداشبورد الهندسي

تم تحديث المنصة لتكون قابلة للتعديل والحذف الشامل، مع معاينة فورية لأي ملف يرفع عليها، واختيار العينات المعروضة قبل المشاركة، وربط التقويم بالشهر النشط:

## 1. التعديل والحذف الكامل على أي عنصر
- **المشاريع الهندسية**: إضافة، تعديل جميع الحقول (الاسم، الموقع، التخصص، الميزانية، المسؤول، نسبة الإنجاز، الحالة، تاريخ المتابعة، الظهور بالمشاركة)، وحذف أي مشروع مباشرة من البطاقة أو نافذة التفاصيل.
- **السيرة الذاتية التفاعلية**: تعديل وإضافة وحذف الخبرات العملية (شاملة النقاط التفصيلية)، المؤهلات العلمية، الشهادات والاعتمادات، المشاريع الكبرى، المهارات، والمسؤوليات.
- **أوامر العمل والتشغيل والصيانة (MEP O&M)**: إضافة وتعديل كامل وحذف لأي أمر عمل مع فلترة مباشرة بالشهر النشط.
- **الملفات وعينات الأعمال والأرشيف الذكي**: تعديل الأسماء والتصنيفات والوسوم وأكواد المخططات والمجلدات، واستبدال أو حذف أي ملف أو مجلد مع إمكانية استعادة الإعدادات الافتراضية.

## 2. اختيار العينات والاطلاع عليها قبل المشاركة
- من زر **«معاينة ومشاركة»** في الشريط العلوي أو من قسم **«عينات الأعمال»**:
  - تحديد أو إخفاء أي عينة عمل أو مشروع أو شهادة بنقرة واحدة.
  - معاينة صفحة العرض التقديمي الكاملة ومعاينة كل ملف على حدة قبل تفعيل أزرار المشاركة (ملف HTML مستقل، طباعة/PDF، واتساب، أو نسخ الملخص).

## 3. معاينة شاملة لأي ملف يُرفع على الداشبورد
- يدعم العارض المدمج (`UniversalFilePreviewModal`) المعاينة الفورية داخل المتصفح دون تعديل النسخة الأصلية:
  - ملفات **PDF** متعددة الصفحات مع التكبير والتنقل والبحث/التنزيل.
  - ملفات **Excel / CSV / TSV** كجداول تفاعلية متعددة الأوراق مع بحث فوري داخل الصفوف.
  - مستندات **Word (.docx)** وعروض **PowerPoint (.pptx)** مع الفقرات والجداول والشرائح والصور المدمجة.
  - مخططات **DXF** ثنائية الأبعاد مع تصفية الطبقات والتكبير، ونماذج **IFC** مع إحصاء عناصر MEP والإنشائي والمعماري.
  - فحص ترويسات ملفات **AutoCAD DWG** و **Revit RVT/RFA** واستخراج الصورة المصغّرة المدمجة عند توفرها، بالإضافة إلى أرشيفات **ZIP** والصور والفيديو والصوت والملفات النصية/البرمجية.

## 4. التقويم الشهري المرتبط بالشهر
- شريط تنقل شهري في أعلى المنصة وقسم **«التقويم الشهري»** المخصص:
  - التبديل بين الأشهر والسنوات يحدث التقويم الشهري، مؤشرات الشهر في الرئيسية، التواريخ الافتراضية، وفلتر أوامر عمل O&M والمشاريع والملفات المؤرخة في ذلك الشهر.
