# المساعد والتصنيف وتخصيص القوائم

## الاستخدام

### مساعد داخل اللوحة

- زر المساعد العائم أسفل الشاشة يفتح محادثة عربية من أي قسم.
- الوضع الافتراضي **دليل محلي قائم على قواعد**؛ لا يحتاج شبكة أو اشتراك، وليس نموذج ذكاء اصطناعي.
- جرّب: «افتح الأرشيف الذكي»، «أضف مشروعًا جديدًا»، «غيّر الثيم والألوان»، «افتح إعدادات القائمة».
- الإجراءات محدودة بفتح الأقسام والنماذج. لا تضيف السجلات أو تحذفها تلقائيًا؛ يُكمل المستخدم النموذج بنفسه. الأسئلة والعبارات المنفية لا تُنفذ إجراءات، ورد النموذج نفسه لا يستطيع إصدار أوامر.
- من **الإعدادات ← مساعد التطوير** يمكن اختيار نموذج عبر خادم وسيط متوافق مع واجهة المحادثة، مع الرد التدريجي أو الرد الكامل.
- **المساعد ليس بيئة تطوير مثل Arena**: لا يقرأ مستودع التطبيق ولا يكتب الشفرة أو يشغّل أوامر نظام. عند ربط نموذج يمكن طلب إرشادات واقتراحات كود، لكن تطبيقها يظل خارج صلاحيات المساعد.

### تصنيف الملفات حسب المحتوى

افتح **الأرشيف الذكي ← رفع وتصنيف ملفات**. تُقرأ عينة من النص محليًا، ثم تُقترح فئة المستند والتخصص والقسم والوسوم. يمكنك مراجعة كل الحقول قبل اعتماد وحفظ الملفات.

| الصيغة | القراءة المحلية |
| --- | --- |
| PDF نصي | حتى 12 صفحة و110 ألف حرف؛ مهلة 15 ثانية |
| DOCX / XLSX / PPTX | استخراج نص XML من المستند والخلايا والشرائح |
| نصوص وCSV وJSON وXML وIFC وDXF النصي | عينة حتى 110 ألف حرف؛ يدعم UTF-8 وUTF-16 بعلامة الترميز |
| صور وPDF ممسوح ضوئيًا | لا توجد قراءة ضوئية محلية؛ تصنيف مبدئي من الاسم والامتداد |
| DWG / RVT وملفات CAD/BIM الثنائية | لا يوجد تحليل هندسي داخلي؛ تحتاج أداة متخصصة |
| DOC / XLS / PPT القديمة، الملفات المحمية أو التالفة | يرجع إلى التصنيف المبدئي عند عدم استخراج نص صالح |

- الحد الأقصى للتحليل المحلي 20 ميجابايت للمستندات و3 ميجابايت للنصوص. هذه حدود القراءة، لا حدود حفظ الملف الأصلي.
- مستندات Office: حتى 40 جزء XML، بحد 2 ميجابايت للجزء و8 ميجابايت إجماليًا قبل قص النص.
- تظهر عبارة «تحليل المحتوى» فقط إذا وُجدت دلالة فعلية في النص. وإلا تظهر عبارة «الاسم والامتداد» مع طلب المراجعة.
- التصنيف **قاعدي بالكلمات المفتاحية، وليس فهمًا دلاليًا أو ضمانًا للدقة**. النسبة المعروضة تقدير للثقة وليست احتمالًا إحصائيًا مقاسًا.
- لا تُرفع الملفات لخادم أثناء التحليل المحلي. تُحفظ النسخ الأصلية دون تعديل في IndexedDB كما في السابق. خيار تحليل الخادم الموجود في الأرشيف منفصل ويتطلب إعدادًا صريحًا.
- مكتبة الملفات العادية تظل تدعم اختيار التصنيف يدويًا، مع رابط واضح للأرشيف للتصنيف حسب المحتوى. لا يعاد تصنيف الملفات القديمة بأثر رجعي.

### ترتيب القائمة وأيقوناتها

من **الإعدادات ← الأقسام والواجهة ← تخصيص القائمة ومكانها وأيقوناتها**:

1. اختر يمين أو يسار أو أعلى الشاشة.
2. استخدم سهمي أعلى وأسفل بجانب القسم لتغيير ترتيبه.
3. اختر «تغيير الأيقونة» ثم إحدى الأيقونات المتاحة.
4. استخدم الإظهار والإخفاء الموجودين أسفل المحرر، أو استعد القائمة الأصلية بزر مخصص لا يمس بقية إعداداتك.

التعديل فوري ومحفوظ تلقائيًا. على الهاتف تبقى القائمة درجًا جانبيًا. تشمل النسخة الاحتياطية والمزامنة ترتيب القائمة وأيقوناتها ومكانها، مع الحفاظ على مخطط المزامنة **الإصدار 2** والتوافق مع النسخ القديمة.

## ربط نموذج محادثة

الواجهة الأمامية لا تتضمن خادم ذكاء اصطناعي أو مفاتيح مزود. يجب نشر خادم وسيط خاص بك، ثم إدخال عنوان HTTPS الكامل، أو مسار على نفس الموقع مثل `/api/assistant` إذا كانت البنية تستضيفه فعلًا. استضافة الصفحات الثابتة وحدها لا توفّر هذا المسار تلقائيًا.

يرسل المتصفح طلب `POST`:

```json
{
  "model": "your-model",
  "messages": [
    { "role": "system", "content": "تعليمات المساعد وسياق محدود للوحة" },
    { "role": "user", "content": "رسالة المستخدم" }
  ],
  "temperature": 0.4,
  "stream": true
}
```

الرد التدريجي من نوع `text/event-stream`:

```text
data: {"choices":[{"delta":{"content":"مرحبًا"}}]}

data: [DONE]

```

أو رد JSON كامل:

```json
{ "choices": [{ "message": { "content": "مرحبًا" } }] }
```

- مفاتيح المزود في متغيرات بيئة الخادم **فقط**؛ لا يوجد حقل لمفتاح داخل الواجهة.
- على الخادم تطبيق المصادقة وحدود الاستخدام والتحقق من الطلبات والسماح بأصل واجهتك عند الحاجة. لا تجعل نقطة النهاية بوابة عامة غير محمية.
- لا تستخدم عنوان `localhost` لخادم في بيئة أخرى؛ المتصفح يتصل من جهاز المستخدم. استخدم عنوانًا متاحًا له أو مسارًا نسبيًا مع وكيل على نفس الموقع.
- عند الإرسال تصل للخادم آخر رسائل المحادثة (حتى 24 رسالة)، واسم اللوحة والقسم الحالي وأعداد المشاريع وأوامر العمل والملفات والأرشيف. لا تُرسل محتويات ملفات الأرشيف أو أسماء المشاريع من هذا المساعد.
- إعدادات الاتصال تحفظ على الجهاز فقط وخارج نسخ المزامنة. المحادثة في الذاكرة وتُصفّر عند إعادة تحميل الصفحة.
- انقطاع الشبكة أو انتهاء مهلة 60 ثانية يظهر رسالة خطأ ولا ينفذ إجراءً.

## التحقق

```bash
npm ci
npm run typecheck
npm test
npm run build
```

الاختبارات تغطي قراءة المحتوى بالعربية والإنجليزية وملفات Office، أولوية المحتوى على الاسم، الرجوع الآمن للملفات غير المدعومة، ترتيب التنقل، توافق المزامنة، حصر أوامر المساعد، إطارات الرد التدريجي وأخطاء الاتصال وعدم تخزين المفاتيح.

كما جرى اختبار إصدار الإنتاج في متصفح Chromium: قراءة PDF عبر العامل المضمن دون CDN، اعتماد الملف وإعادة تحميله من IndexedDB، مكان القائمة وحفظ التفضيلات، درج الهاتف وحدود نافذة المساعد، واتصال محادثة برد تدريجي تجريبي. لم يُختبر اتصال فعلي بمزود ذكاء اصطناعي لعدم توفير خادم وسيط مُهيّأ.

## التقويم الشهري ودوام الحرم

- يظهر تقويم شهري صغير أعلى يمين **نظرة عامة**، مع شبكة أيام تبدأ بالسبت، تمييز اليوم الحالي واختيار أي يوم، وأسهم لتصفح الشهور وزر العودة لليوم.
- الأيام ميلادية، والتوقيت ثابت على **مكة المكرمة (`Asia/Riyadh`)** حتى لو كان الجهاز مضبوطًا على منطقة زمنية أخرى.
- الدوام مضبوط على **الحرم — من ٩ صباحًا إلى ٥ مساءً (٨ ساعات)**. عند اختيار اليوم يظهر الوقت المتبقي قبل البداية أو حتى النهاية، مع شريط لانقضاء وقت الدوام وتحديث تلقائي كل ٣٠ ثانية.
- لم تُفترض أيام راحة أو إجازات؛ يظهر تنبيه بذلك داخل البطاقة. هذا عرض لموعد الدوام، وليس تسجيل حضور وانصراف أو إرسال تنبيهات نظام.
- على الهاتف تبقى البطاقة في بداية الصفحة بعرض يناسب الشاشة.

## ملفات مستقلة لكل مشروع في السيرة الذاتية

داخل **السيرة الذاتية والخبرات ← المشاريع الهندسية الكبرى المنفّذة**، توجد أزرار «ملفات المشروع» و«إضافة ملفات» في كل بطاقة مشروع.

- ارفع ملفًا واحدًا أو عدة ملفات بأي صيغة: مخططات أو صور أو تقارير. تظهر قائمة المرفقات وعددها وأحجامها داخل مشروعها فقط.
- يمكن تنزيل كل ملف بصيغته واسمه ومحتواه الأصلي، أو حذفه بعد تأكيد مستقل. إلغاء التأكيد لا يغير الملف.
- المرفقات مرتبطة بمعرّف مشروع السيرة الثابت، وليس بالاسم؛ الأسماء المتطابقة للمشاريع أو الملفات لا تخلط المرفقات.
- التخزين في قاعدة **IndexedDB** مستقلة باسم `mhmed-cv-project-files`. الدفعة الواحدة تُحفظ بمعاملة واحدة؛ عند فشل الكتابة لا تُحفظ دفعة جزئية.
- الملفات باقية بعد تحديث الصفحة، لكنها تخص هذا المتصفح وهذا الجهاز فقط. **لا تدخل مرفقات المشاريع في مزامنة السيرة أو نسخة JSON الاحتياطية**؛ احتفظ بنسخة أصلية أو نزّلها قبل مسح بيانات المتصفح. هذه الإضافة لا تغيّر مخطط المزامنة الإصدار ٢ ولا تنقل الملفات إلى الأرشيف تلقائيًا.
- واجهة الملفات لا تنفذ المحتوى أو تعرض HTML مرفوعًا داخل التطبيق؛ التنزيل يحافظ على الملف دون تعديل.

اختبارات الإضافة: المنطقة الزمنية وحدود الدوام والسنة الكبيسة والتنقل بين السنوات، عزل مرفقات المشاريع، سلامة بايتات الملفات، الرفع المتعدد والحذف المعزول. جرى أيضًا اختبار واجهة إصدار الإنتاج في Chromium على الكمبيوتر والهاتف: مكان التقويم، تحديث نهاية الدوام، رفع المرفقات وتنزيلها وإعادة تحميلها وحذفها وإلغاء الحذف، دون تجاوز أفقي للشاشة أو أخطاء تشغيل.
